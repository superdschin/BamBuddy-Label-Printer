# BamBuddy Label Printer

[Deutsch](#deutsch) | [English](#english)

## Deutsch

**BamBuddy Label Printer** ist eine Windows-Anwendung zum Drucken von Filamentspulen-Etiketten aus [BamBuddy](https://github.com/maziggy/bambuddy) mit einem **NIIMBOT B1** Bluetooth-Drucker.

### Funktionen
- Etikettendaten aus der BamBuddy-API abrufen
- QR-Code für eine Spule erzeugen
- Etikettenvorschau, PNG-Export und Druck über Bluetooth Low Energy
- Deutsche und englische Benutzeroberfläche
- Individuell konfigurierbare Serveradresse, QR-Basisadresse und API-Schlüssel

### Voraussetzungen
- Windows 10/11 (64 Bit) mit Bluetooth Low Energy
- NIIMBOT B1
- Erreichbarer BamBuddy-Server mit API-Schlüssel
- Getestetes Etikettenformat: **40 × 30 mm**

## English

**BamBuddy Label Printer** is a Windows application for printing filament spool labels from BamBuddy using a **NIIMBOT B1** Bluetooth printer.

### Features
- Fetch spool data from the BamBuddy API
- Generate spool QR codes
- Label preview, PNG export, and Bluetooth Low Energy printing
- German and English interface
- Configurable server URL, QR base URL, and API key

### Requirements
- Windows 10/11 (64-bit) with Bluetooth Low Energy
- NIIMBOT B1 printer
- Reachable BamBuddy server with API key
- Tested label size: **40 × 30 mm**

### Status
**v1.0.0 is available!** Download the portable Windows version from [Releases](https://github.com/superdschin/BamBuddy-Label-Printer/releases/tag/v1.0.0). Extract the ZIP and run `BamBuddy-Label-Printer.exe`; no Python installation is required. Third-party license notices are included in the download.
